# فروشگاه تخصصی عینک استوک اورجینال جهانی (Stock Jahani)

یک سامانه فروشگاهی آنلاین مدرن و فول‌استک، طراحی شده به صورت کاملاً مستقل (Standalone)، مبتنی بر **React 18**، **TypeScript**، **Tailwind CSS**، **Express** و پایگاه داده ابری **Google Firebase Firestore**.

---

## ⚠️ اطلاعیه مهم امنیتی: ابطال و جایگزینی فوری توکن‌ها (Token Rotation Advisory)

> **هشدار امنیتی بسیار مهم:**
> هرگونه توکن ربات تلگرام یا کلمه عبور مدیریتی که قبلاً در سورس‌کد یا فایل‌های آزمایشی قرار داشته است، باید **افشا شده (Compromised)** در نظر گرفته شود.
> 
> **اقدام ضروری قبل از استفاده در محیط عملیاتی:**
> 1. وارد بات **@BotFather** در تلگرام شوید و برای ربات خود با دستور `/revoke` توکن جدید (Token Rotation) دریافت نمایید.
> 2. رمز عبور مدیریت فروشگاه (`ADMIN_PASSCODE`) را در فایل `.env` به یک رمز عبور پیچیده و قوی تغییر دهید.
> 3. هیچ‌گاه توکن‌ها، کلیدهای خصوصی یا فایل `.env` را به مخازن عمومی گیت‌پوش نکنید.

---

## 🚀 راهنمای اجرای مستقل روی سرور شخصی یا هاست (Standalone Deployment)

این پروژه برای اجرا روی هرگونه سرور لینوکسی (Ubuntu/Debian/CentOS)، هاست‌های ابری (Liara, Hetzner, DigitalOcean) و داکر به صورت ۱۰۰٪ مستقل طراحی شده است و هیچ وابستگی به محیط توسعه ندارد.

### پیش‌نیازها
* **Node.js**: نسخه 18 یا بالاتر (توصیه شده: LTS v20+)
* **npm**: نسخه 9 یا بالاتر

### مرحله ۱: کلون یا استخراج فایل‌ها و نصب وابستگی‌ها
```bash
# نصب پکیج‌های پروژه
npm install
```

### مرحله ۲: تنظیم متغیرهای محیطی (.env)
یک فایل به نام `.env` در ریشه پروژه ایجاد کرده و متغیرهای زیر را در آن تنظیم کنید:

```env
# رمز عبور ورود به پنل مدیریت (الزامی)
ADMIN_PASSCODE=your_strong_admin_passcode_here

# تنظیمات ربات تلگرام جهت دریافت نوتیفیکیشن سفارشات (اختیاری اما توصیه شده)
TELEGRAM_BOT_TOKEN=your_new_rotated_bot_token_from_botfather
TELEGRAM_CHAT_ID=your_telegram_channel_or_group_id

# پورت اجرای وب‌سرور (پیش‌فرض: 3000)
PORT=3000
NODE_ENV=production
```

### مرحله ۳: بیلد و کامپایل پروژه
```bash
npm run build
```
این دستور کلاینت را در پوشه `dist/` به صورت بهینه‌شده کامپایل کرده و سرور بک‌اند را به یک فایل باندل شده مستقل در `dist/server.cjs` تبدیل می‌کند.

### مرحله ۴: اجرای سرویس
```bash
npm run start
```
سرور بر روی پورت تعیین شده اجرا شده و فروشگاه در دسترس خواهد بود. برای اجرای دائمی در پس‌زمینه سرور می‌توانید از **PM2** استفاده کنید:

```bash
npm install -g pm2
pm2 start dist/server.cjs --name "stock-jahani"
pm2 save
pm2 startup
```

## 🛡️ معماری داده و امنیت (Single Source of Truth)

1. **Firestore به عنوان تنها منبع حقیقت (Single Source of Truth):**
   * تمامی اطلاعات محصولات (`products`)، سفارشات خریداران (`orders`)، تنظیمات فروشگاه (`settings`) و لاگ‌ها مستقیماً و منحصراً در Firestore ذخیره می‌شوند.
   * فایل‌های موازی قدیمی (`store.json`, `inMemoryStore`, `deletedProductIds`, `/api/sync-all`) کاملاً از پروژه حذف شده‌اند تا از هرگونه Race Condition، Overwrite یا ناهمزمانی داده جلوگیری شود.
   * حافظه محلی مرورگر (`localStorage`) صرفاً برای سبد خرید جاری (`cart`) و علاقمندی‌های کاربر استفاده می‌شود و هیچ داده حساسی در آن قرار ندارد.

2. **قوانین امنیتی Firestore (`firestore.rules`):**
   * دسترسی ویرایش و حذف محصولات منحصراً به مدیر احراز هویت‌شده محدود است.
   * خریداران فقط مجاز به ساخت سفارش با داده‌های معتبر بوده و دسترسی فهرست کردن (`list`) تمامی سفارشات سایر مشتریان برای عموم مسدود شده است.
   * تنظیمات فروشگاه و گزارشات سیستمی در برابر دستکاری عمومی کاملاً قفل شده‌اند.
